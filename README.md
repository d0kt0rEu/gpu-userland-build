# gpu-userland-build

GitHub Actions build of [UniXNU](https://github.com/UniXNU/UniXNU)'s GPU userland for iPadOS 17: Turnip (Mesa freedreno Vulkan
with the Darwin kernel backend), the AdrenoMetal plugin and the GPU add-on. Run the "GPU userland (iOS 17)" workflow by hand; the
binaries come back as the `gpu-userland-ios17` artifact. Everything is built from public sources at the given UniXNU commit.
